## 🚀 Главный проект

### [T-Invest Analytics](https://github.com/Kos5o4ka/tinvest-analytics)

Локальная аналитика брокерских счетов Т-Инвестиций. Один файл, только стандартная библиотека Python.

- 📊 портфель, доходность, выплаты по дням, комиссии и налоги
- 🧮 облигации: точная доходность с амортизациями, стресс-тест, риски дефолта, сценарии ключевой ставки
- 🔎 скринер, карта рынка, кредитные рейтинги, первичные размещения
- 🔒 токен только на чтение, все данные остаются на вашем компьютере

## 🛠 Чем занимаюсь
